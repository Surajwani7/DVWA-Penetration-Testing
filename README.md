# DVWA Penetration Testing Report

## Project Overview

A basic penetration testing assessment performed on
Damn Vulnerable Web Application (DVWA).

## Vulnerabilities Identified

- SQL Injection – High
- Reflected XSS – Medium
- Stored XSS – High
- Command Injection – High
- Local File Inclusion – Critical
- Brute Force – Medium

## Tools Used

- Burp Suite
- OWASP ZAP
- sqlmap
- Nikto
- Nmap

## Methodology

- Reconnaissance
- Vulnerability Identification
- Exploitation
- Reporting
- Remediation
